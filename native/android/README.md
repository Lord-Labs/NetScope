# Android collection boundary

Planned Kotlin Tauri plugin, service, Room ledger and short WorkManager sync jobs.
No collector or plugin is implemented in the foundation. G02 must prove the
non-VPN measurement/lifecycle scope before D01 chooses the service approach.

The React UI lives in apps/client. The Tauri host lives in apps/client/src-tauri;
initialize its generated Android runner only with the documented SDK/JDK/NDK.
The runner is a host, not the durable measurement service. Kotlin owns collection
and storage even when the Activity/WebView is gone. Only scoped commands/events
cross the UI bridge. Never use a JavaScript timer as background metering.
