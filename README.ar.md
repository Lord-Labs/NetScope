# NetScope

منصة مفتوحة المصدر لفهم استهلاك الإنترنت المشترك وتقسيم تكلفة الباقة حسب الاستخدام.

**الحالة الحالية: أساس المشروع، وليس تطبيق قياس مكتملًا.** توجد واجهة Flutter
أولية، نقطة فحص صحة للخادم، قواعد تصميم، عقود بيانات، وخطة عمل بإيشوز مترابطة.
أول إصدار مفيد يستهدف Windows محليًا. اعتماد Android يحتاج اختبار القياس أولًا.

## القرارات المعتمدة

- تطبيق Windows وAndroid بواجهة Flutter. القياس الأصلي بـRust على Windows
  وKotlin على Android. التخزين المحلي SQLite.
- الموقع اللاحق Svelte؛ الخادم Hono على Cloudflare Workers؛ البيانات D1 مع
  Drizzle؛ المصادقة Better Auth بعد اختبار تكاملها.
- لا VPN، ولا تعديل للراوتر، ولا root، ولا Student Pack، ولا استضافة مدفوعة إلزامية.
- المستخدم يربط أجهزته بحساب واحد عند إضافة المرحلة الجماعية.
- هدف القياس شبكة السكن فقط. عداد Wi-Fi الذي يشمل نقل الملفات المحلي لا يُعرض
  باعتباره استهلاك باقة مؤكدًا.
- الجميع داخل المجموعة يرى إجمالي كل عضو وحالة القياس؛ تفاصيل الأجهزة لصاحبها.
- كامل التكلفة يُقسم بنسبة الاستخدام خلال فترة بداية ونهاية يحددها المسؤول،
  مع تسجيل تكلفة الباقة الأساسية والإضافات يدويًا.
- البيانات المفقودة ليست صفرًا، والتسوية تظل مبدئية حتى مراجعة الفجوات.
- النظام تعاوني ولا يضمن كشف حذف التطبيق أو استخدام جهاز غير مسجل.

## الإطلاق السريع

أول ألفا مفيدة تكون محلية على Windows: اختيار شبكة السكن، قياس فعلي مع بيان
حدوده، حفظ محلي، تاريخ استخدام، إظهار الفجوات، وتصدير تقرير. لا نؤخرها ببناء
تسجيل الدخول أو الموقع أو الدفع. Android يبقى مسارًا منفصلًا حتى إثبات دقته.

الواجهة مستوحاة من هدوء Arc: مساحات محايدة، لون أساسي محدود، أرقام واضحة،
حركة لها معنى، ودعم العربية وRTL والوضع الفاتح والداكن.
